# 🏃‍♂️ Personal Fitness Tracker 💪

A simple Python-based **Personal Fitness Tracker** that helps users
record workout activities, review fitness metrics, filter activity
records, generate progress reports, and visualize workout data with
charts.

> 🎯 **Goal:** Track your daily fitness activities and understand your
> progress through useful statistics and visual dashboards.

------------------------------------------------------------------------

## ✨ Features

- 📝 **Log New Activity** — Record activity type, duration (minutes),
  and calories burned.
- 📊 **View Fitness Metrics** — Check total calories burned, average
  session duration, and activity frequency.
- 🔎 **Filter Activities** — Find records by activity type and date
  range.
- 📄 **Generate Summary Report** — View the tracking period, total
  sessions, and activity-wise breakdown.
- 📈 **Visualize Progress** — Display charts for workout duration,
  calories burned over time, activity distribution, and correlations.
- 🚪 **Exit** — Close the tracker safely.

## ▶️ How to Run

1.  Install Python 3 on your computer.

2.  Open the project folder in VS Code or a terminal.

3.  Install the libraries used by the project:

    ``` bash
    pip install numpy pandas matplotlib
    ```

4.  Run your main Python file (replace `main.py` with your actual
    filename):

    ``` bash
    python main.py
    ```

5.  Select an option from the menu and follow the instructions.
